# 《乒乓》(PING PONG) 实体桌游电子版 - 部署与游玩指南

本压缩包包含完整的 **Web前端页面 (`index.html`)** 与 **多人手机在线联机服务端 (`server.js`)**。

## 1. 本地直接运行（1人人机 / 4人双打AI / 同屏对战 / 同设备多窗口联机）
直接用手机或电脑浏览器打开 `index.html` 即可游玩：
- **1v1 人机对战**：还原1盒27张比赛牌+1张发球牌，单挑智能乒乓AI。
- **2v2 四人双打**：还原2盒54张比赛牌，严格按照 `① -> ②(斜对) -> ③(正对) -> ④(斜对) -> ①(正对)` 顺序交替接球，丢分方小队可自由指定下一回合发球人。
- **双重拼接校验**：同时校验 **来球方位+轨迹弧度（左/中/右 × 直线/斜线/弧线/擦网折线）** 与 **图5官方 A~J 10×10 对应表**。当一张牌的2条轨迹均可接招时，玩家可自由切换用哪条线当入线、哪条线留给对手当出线。
- **完整支持行动 A / B / C 与鏖战模式**：
  - **行动A**：打1张补1张。
  - **行动B**：弃2张手牌、抽2张牌，再打1张牌（不补牌，体力上限-1）。被扣杀时也可先使用行动B找对子！
  - **行动C**：对手打出擦网球牌（仅 `E / F / G` 带红色商标点）或对手刚执行行动C时解锁，打出2张完全相同的牌扣杀，强制对手也必须以2张相同的牌接招。

## 2. 部署到你自己的服务器（供多部手机异地/局域网实时联机）
1. 将本目录上传至你的服务器，执行：
   ```bash
   npm install
   node server.js
   ```
   服务端默认监听 `8080` 端口（可通过 `PORT=9000 node server.js` 自定义端口）。
2. 将 `index.html` 放到 Nginx / Apache 静态目录（或直接发给朋友在手机上打开）。
3. 玩家们点击右上角 **【模式/联机】**，在“WebSocket 服务器地址”填入 `ws://你的服务器IP:8080`（若配置了HTTPS反代则填 `wss://你的域名/ws`），输入相同的4位房间号，即可4部手机实时同台对战！
